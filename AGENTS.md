# ThorShield project instructions

## README language policy

- Keep every project README bilingual: English and French in the same file, with language navigation links.
- Update both language sections together. Keep features, prerequisites, commands, status, and limitations equivalent.
- Clearly distinguish documentation translations from languages actually supported by the software.
- Use generic paths and synthetic examples. Do not include private machine reports, personal paths, credentials, or personal contact details in tracked documentation.

## Règle linguistique des README

- Maintenir chaque README du projet en anglais et en français dans le même fichier, avec des liens de navigation entre les langues.
- Mettre à jour les deux sections ensemble. Garder des fonctionnalités, prérequis, commandes, statuts et limites équivalents.
- Distinguer les traductions de la documentation des langues réellement prises en charge par le logiciel.
- Utiliser des chemins génériques et des exemples synthétiques. Ne pas inclure de rapports privés de machine, chemins personnels, identifiants secrets ou coordonnées personnelles dans la documentation suivie par Git.
